# AutoReply for Windows

Windows ইনস্টলার (`AutoReply-Setup-x.y.z.exe`), যা ওয়েব WhatsApp ও Telegram-এ আসা মেসেজের উত্তর স্বয়ংক্রিয়ভাবে দেয়,
Android AutoReply অ্যাপের একই নিয়ম-ব্যবস্থা (হুবহু/প্রায়/প্যাটার্ন/Regex/শব্দ থাকলেই, গ্রুপ ও ব্যক্তি সুইচ) এবং ঐচ্ছিক AI চ্যাট দিয়ে।

## কীভাবে কাজ করে
- অ্যাপের ভেতরে web.whatsapp.com ও web.telegram.org খোলা থাকে (আলাদা, স্থায়ী লগইন)।
- নতুন মেসেজ এলে নিয়ম মেলানো হয়; না মিললে AI চালু থাকলে AI উত্তর দেয়; তারপর উত্তর টাইপ করে পাঠানো হয়।
- জানালা বন্ধ করলে ট্রে-তে চলতে থাকে। ট্রে আইকনের মেনু থেকে পুরো বন্ধ করা যায়।
- Messenger ট্যাব শুধু দেখার জন্য, তাতে স্বয়ংক্রিয় উত্তর নেই।

## সীমা
- ওয়েব পাতার কাঠামো বদলালে (WhatsApp/Telegram আপডেটে) মেসেজ চেনা বন্ধ হতে পারে; তখন `adapter.js`-এর সিলেক্টর ঠিক করতে হবে।
- Telegram-এ শুধু ব্যক্তির সাথে সরাসরি চ্যাটে উত্তর যায় (চ্যানেল/বট/মিউট বাদ)।
- একই চ্যাটে ঘণ্টায় সর্বোচ্চ ১০টি উত্তর (দুই অটো-রিপ্লাই বটের চক্র ঠেকাতে)।

## ডেভেলপমেন্ট
```
cd windows
npm install
npm test        # নিয়ম, AI, সিদ্ধান্ত ও adapter-এর নিয়ন্ত্রণ-প্রবাহের টেস্ট
npm start       # চালিয়ে দেখা
npm run dist    # (Windows-এ) ইনস্টলার বানানো; সাধারণত GitHub Actions বানায়
```
